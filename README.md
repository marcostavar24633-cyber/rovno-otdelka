# «Ровно» — лендинг отделки помещений в Ульяновске

Статический одностраничный сайт для GitHub Pages: `index.html` (HTML + CSS + JS в одном файле), без сборки.

Сайт: https://marcostavar24633-cyber.github.io/rovno-otdelka/

## Файлы
- `index.html` — лендинг
- `404.html` — страница «не найдено»
- `privacy.html` — политика конфиденциальности (шаблон, дополните по 152-ФЗ)
- `assets/` — favicon и картинка для соцсетей (`og.png`)
- `robots.txt`, `sitemap.xml`, `.nojekyll`
- `brief.md` — бриф проекта: аудитория, УТП, ключевые запросы, дизайн-решение

## Как подключить форму
GitHub Pages не умеет принимать заявки сам. Зарегистрируйтесь в Formspree (или аналоге), создайте форму и вставьте адрес в начале скрипта:

```js
const CONFIG = { formEndpoint: "https://formspree.io/f/xxxxxxx", phone: "+7 999 123-45-67" };
```

Пока адрес пустой, форма проверяет поля и предлагает позвонить. Не кладите в код токены ботов и пароли — репозиторий публичный.

## Свой домен
Добавьте файл `CNAME` с доменом, поменяйте адрес сайта в `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml`, `404.html`, настройте DNS у регистратора и включите Enforce HTTPS в Settings → Pages.

## Фишки и где их включать
Файлы: `index.html` (разметка), `assets/css/site.css` (стили и темы), `assets/js/site.js` (поведение).
Все переключатели — объект `CONFIG.features` в начале `assets/js/site.js` (`true` / `false`):

| Фишка | Ключ | Где в коде |
|---|---|---|
| Прелоадер 0–100 % со шторкой | `preloader` | `#preloader`, `.preloader` |
| Инерционный скролл (Lenis) | `smoothScroll` | блок «Lenis» в site.js |
| Кастомный курсор: точка + кольцо, «Смотреть» над фото, «Тяни» над слайдерами | `cursor` | `#cursor`, атрибуты `data-cursor="view|drag"` |
| Магнитные кнопки | `magnet` | атрибут `data-magnet` |
| 3D-наклон карточек | `tilt` | класс `.tilt` |
| Заголовок hero по буквам | `heroChars` | `.hero__line` |
| Заголовки секций по строкам из-под маски | `titleLines` | класс `.reveal-title` |
| Раскрытие картинок шторкой | `imageReveal` | `.svc`, `.case__img`, `.person__ph`, `.ba` |
| Параллакс фото | `parallax` | hero и карточки услуг |
| Горизонтальный скролл проектов (≥1024 px) | `horizontalWorks` | `#proekty`; на мобильных — свайп |
| Накладывающиеся карточки гарантий | `stackCards` | `#stack` |
| Скорость бегущих строк от скорости скролла | `marqueeVelocity` | `.marquee[data-velocity]` |
| Шторка при переходе на другие страницы | `pageTransition` | ссылки на `*.html` |

Всегда включено: полноэкранное меню (круг от бургера, фото на фоне по наведению), mega-menu «Услуги», панели «Заказать звонок» и кейса (крестик, фон, Esc, блокировка прокрутки, фокус-ловушка), шапка-стекло с прогресс-баром (прячется вниз / появляется вверх), счётчики, калькулятор с анимированной суммой, квиз на 5 шагов, слайдер «До / После», перетаскиваемые отзывы, FAQ-аккордеон, плавающая кнопка Telegram, плавающие подписи полей и галочка при отправке, светлая / тёмная тема.

При `prefers-reduced-motion` анимации отключаются, контент виден сразу. Если CDN с библиотеками не ответил (загрузчик пробует jsDelivr → cdnjs → unpkg), сайт работает без анимаций.

**Калькулятор:** цены за м² — в радиокнопках «Вид отделки» в index.html (10 000 / 15 000 / 20 000). Доп. опции и их цены — `CONFIG.calc.options` (цена 0 = опция не меняет сумму, а попадает в заявку).
**Квиз:** подарок в конце — `CONFIG.quizGift` (пусто = не показывается).
**Кейсы:** `CONFIG.cases` — площадь, срок, бюджет показываются, только когда заполнены.

## Что подготовить (фото и видео)
- Фото объектов для блока «Проекты» — 5–8 квартир, по 3–6 кадров, горизонтальные, 2400 px по длинной стороне (сейчас там визуализации с подписью).
- «До / После» — 2 кадра одной комнаты с одной точки съёмки.
- Команда — 4 портрета по пояс на нейтральном фоне, вертикальные 3:4, имена и роли.
- Отзывы — 2 видеоотзыва 30–60 с (вертикальные) и 3–5 текстовых с именем и ЖК.
- Логотипы поставщиков материалов, с которыми работаете (SVG или PNG на прозрачном фоне), — только с их согласия.
- Карта — адрес офиса или зона выезда (можно вставить виджет Яндекс.Карт в `.footer__map`).
- По желанию: короткое видео интерьера для фона первого экрана (MP4, 10–15 с, без звука, до 5 МБ).

**После правок CSS или JS** увеличьте номер `?v=` у `site.css` и `site.js` в `index.html`, чтобы браузеры посетителей сразу взяли новую версию.
