# «Ровно» — лендинг отделки помещений в Ульяновске

Статический одностраничный сайт для GitHub Pages: `index.html` (HTML + CSS + JS в одном файле), без сборки.

Сайт: https://marcostavar24633-cyber.github.io/rovno-otdelka/

## Файлы
- `index.html` — лендинг
- `404.html` — страница «не найдено»
- `privacy.html` — политика конфиденциальности (шаблон, дополните по 152-ФЗ)
- `assets/` — favicon и картинка для соцсетей (`og.png`)
- `robots.txt`, `sitemap.xml`, `.nojekyll`
- `brief.md` — бриф проекта: аудитория, УТП, ключевые запросы, дизайн-решение

## Как подключить форму
GitHub Pages не умеет принимать заявки сам. Зарегистрируйтесь в Formspree (или аналоге), создайте форму и вставьте адрес в начале скрипта:

```js
const CONFIG = { formEndpoint: "https://formspree.io/f/xxxxxxx", phone: "+7 999 123-45-67" };
```

Пока адрес пустой, форма проверяет поля и предлагает позвонить. Не кладите в код токены ботов и пароли — репозиторий публичный.

## Свой домен
Добавьте файл `CNAME` с доменом, поменяйте адрес сайта в `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml`, `404.html`, настройте DNS у регистратора и включите Enforce HTTPS в Settings → Pages.

## Меню и анимации — где настраивать
Все числовые настройки движения — в объекте `CONFIG.motion` в начале `<script>` в `index.html`:
`revealStagger`, `heroWordDelay`, `parallax`, `magnet`, `magnetMax`, `tiltMax`, `counterMs`, `faqMs`, `headerHideAfter`. Поставьте 0, чтобы выключить параллакс или магнит.

Длительности и кривые CSS — переменные `--ease`, `--ease-out` и блок `/* ===== Меню, панели и анимации ===== */` в `<style>`.

- **Мобильное меню** (`#mobile-menu`, кнопка `#burger`): бургер → крестик, панель справа, затемнение с размытием, пункты по очереди (`.oc__item`, задержка `--i`). Закрывается крестиком, по фону, Esc и при переходе по ссылке; прокрутка блокируется; фокус не уходит из меню.
- **Выпадающее меню «Услуги»** (`#dd-wrap`): по наведению и по клику, Esc, клик мимо.
- **Боковая панель «Перезвоните мне»** (`#callback`): открывается любой кнопкой с `data-open="callback"`.
- **Шапка**: прячется при прокрутке вниз, появляется при прокрутке вверх, после первого экрана — компактная (`.is-hidden`, `.is-compact`).
- **Анимации**: заголовок по словам и параллакс фона (hero), появление блоков при скролле (`.reveal`), кнопки-магниты (`data-magnet`), 3D-наклон карточек (`.tilt`), счётчики цен (`.count[data-to]`), плавный FAQ, бегущая строка (`.marquee`, скорость — `animation: marquee 38s`).
- При включённом в системе «уменьшить движение» (`prefers-reduced-motion`) всё декоративное движение отключается.
